`CASE WHEN THEN` in SQL is like **if–else**. It lets you create conditions inside a query.

Think of it as:

**CASE → check condition → WHEN → if true → THEN → return value → ELSE → otherwise → END**

---

## 1) Basic Syntax

```sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE result3
END
```

Example:

```sql
SELECT 
    name,
    salary,
    CASE
        WHEN salary < 30000 THEN 'Low Salary'
        WHEN salary BETWEEN 30000 AND 60000 THEN 'Average Salary'
        ELSE 'High Salary'
    END AS salary_category
FROM Employee;
```

Output:

| name | salary | salary_category |
| ---- | ------ | --------------- |
| A    | 20000  | Low Salary      |
| B    | 50000  | Average Salary  |
| C    | 90000  | High Salary     |

### Logic to remember:

```
CASE
   WHEN condition is TRUE
        THEN give this value
   ELSE
        give this value
END
```

# 2) CASE inside SELECT (creating a new column)

Table:

Employee

| id | name | salary |
| -- | ---- | ------ |
| 1  | Raj  | 25000  |
| 2  | Amit | 70000  |
| 3  | Neha | 45000  |

Query:

```sql
SELECT 
    name,
    CASE
        WHEN salary > 50000 THEN 'Rich'
        ELSE 'Normal'
    END AS status
FROM Employee;
```

Result:

| name | status |
| ---- | ------ |
| Raj  | Normal |
| Amit | Rich   |
| Neha | Normal |

# 3) Multiple WHEN conditions

```sql
SELECT
    name,
    age,
    CASE
        WHEN age < 18 THEN 'Child'
        WHEN age >=18 AND age < 60 THEN 'Adult'
        WHEN age >=60 THEN 'Senior'
    END AS category
FROM Person;
```

Important:
SQL checks **top to bottom**.

If first condition matches, it stops.

Example:

```sql
CASE
   WHEN salary > 30000 THEN 'A'
   WHEN salary > 60000 THEN 'B'
END
```

For salary = 70000

Output = `A`

because first condition is already true.

# 4) CASE with COUNT() (very important for LeetCode)

Wrong:

```sql
COUNT(
    CASE 
       WHEN state='approved' THEN 1
       ELSE 0
    END
)
```

Why wrong?

COUNT counts non-null values:

```
1  → counted
0  → counted
NULL → ignored
```

So both approved and rejected are counted.

---

Correct:

```sql
COUNT(
    CASE
        WHEN state='approved' THEN 1
    END
)
```

Example:

Table:

| id | state    |
| -- | -------- |
| 1  | approved |
| 2  | pending  |
| 3  | approved |

Inside CASE:

| state    | CASE result |
| -------- | ----------- |
| approved | 1           |
| pending  | NULL        |
| approved | 1           |

COUNT counts:

```
1 + 1 = 2
```

Output:

```
approved_count = 2
```

# 5) CASE with SUM()

This is another very common pattern.

Syntax:

```sql
SUM(
    CASE
       WHEN condition THEN value
       ELSE value
    END
)
```

Example:

Count approved:

```sql
SELECT
SUM(
    CASE
       WHEN state='approved' THEN 1
       ELSE 0
    END
) AS approved_count
FROM Orders;
```

Logic:

| state    | value |
| -------- | ----- |
| approved | 1     |
| pending  | 0     |
| approved | 1     |

SUM:

```
1+0+1 = 2
```

# 6) CASE with GROUP BY

Example: Count salary categories

```sql
SELECT
CASE
    WHEN salary < 30000 THEN 'Low'
    WHEN salary >=30000 THEN 'High'
END AS category,
COUNT(*) AS total
FROM Employee
GROUP BY
CASE
    WHEN salary < 30000 THEN 'Low'
    WHEN salary >=30000 THEN 'High'
END;
```

Output:

| category | total |
| -------- | ----- |
| Low      | 5     |
| High     | 10    |

---

# 7) CASE in ORDER BY (sorting custom order)

Example:

You want approved first:

```sql
SELECT *
FROM Orders
ORDER BY
CASE
    WHEN state='approved' THEN 1
    WHEN state='pending' THEN 2
    ELSE 3
END;
```

Output order:

```
approved
pending
rejected
```

# 8) Simple CASE (another form)

When comparing one column:

Syntax:

```sql
CASE column
    WHEN value1 THEN result1
    WHEN value2 THEN result2
    ELSE result3
END
```

Example:

```sql
SELECT
name,
CASE department
    WHEN 'IT' THEN 'Technical'
    WHEN 'HR' THEN 'Management'
    ELSE 'Other'
END AS dept_type
FROM Employee;
```

## Quick memory trick:

### CASE WHEN = IF ELSE

SQL:

```sql
CASE
WHEN condition
THEN answer
ELSE other_answer
END
```

Programming:

```java
if(condition)
{
   answer;
}
else
{
   other_answer;
}
```

---

### Most used LeetCode patterns:

**Counting conditionally**

```sql
COUNT(CASE WHEN condition THEN 1 END)
```

**Summing conditionally**

```sql
SUM(CASE WHEN condition THEN 1 ELSE 0 END)
```

**Creating categories**

```sql
CASE WHEN condition THEN label END
```

If you remember these 3 patterns, most SQL `CASE` problems become easy.
